## 3. What was implemented

`RestrictedExcerptPolicy.cs` (rewritten) plus the call site in `WriteEvidencePacketArtifact` and an
`EmbeddedResource` entry in the worker csproj.

**Scope is the shared manifest, not the registry.** The worker embeds the C1 containment manifest as
`BioStack.KnowledgeWorker.SourceRights.drugbank-containment.v1.json`, so both surfaces contain exactly
one scope and containment no longer depends on an optional registry file being supplied.

The `EmbeddedResource` points at `SourceRights/drugbank-containment.v1.json` — the in-project copy
generated by `scripts/sync-source-rights.mjs` — not at `shared/` directly. My first attempt referenced
`..\..\..\shared\...`, which builds locally but leaves the Docker build context rooted at `backend/`
without the file. The sync script exists for exactly that reason and CI rejects a stale copy;
`node scripts/sync-source-rights.mjs --check` reports the copies current. I verified the synced copy is
semantically identical to `shared/` (formatting only) and did not edit either file.

**Fail-closed (C1-01, C1-04).** If the manifest resource is missing or names no ids and no hosts, the
policy **throws** rather than emitting. A rights control that disables itself when its configuration is
absent is not a control. The registry, when present, may only **widen** matching through the DrugBank
class's aliases; it can never narrow it. Neither a missing registry nor a partial `permittedContent`
declaration releases these excerpts — release requires a reviewed superseding C1 decision.

**Matching.** Manifest `sourceIds` (class + 24 aliases) exact and case-insensitive, plus `hostSuffixes`
matched on **host labels**: `host == suffix` or `host.EndsWith("." + suffix)`. Never substring —
`notdrugbank.com` and `drugbank.com.example.org` must not match, and a lookalike domain must not slip
through. Six theory cases pin this.

**Scope narrowed to C1 (Codex's marker finding).** The previous revision derived scope from the registry
`dataBoundary` marker, which silently reached six classes including the two retired authorization
placeholders and the ISSN paper. That expanded an approved decision without review, and conflated C3 —
which retires **authorization classes**, not their literature — with a decision to withhold text. The
policy now contains DrugBank and nothing else.

**Preservation.** Only `quote` becomes null; `sourceRef` and `pageOrSection` survive, so a reviewer sees
what a claim rested on and where. The schema already permits a null quote, so no schema change was
needed; because evidence items are `additionalProperties: false`, withholding is recorded once at packet
level as an `ops.qualityFlags` entry appended to existing review flags. The in-memory packet is cloned,
inputs are byte-identical after a run (asserted), and no run snapshot was rewritten.

**Correction (Codex).** The previous revision said 28 claims "survive excerpt removal". That was an
unsupported claim about evidentiary substance. A co-citation existing is not evidence that it supports
the claim — the afamelanotide case earlier in this collaboration is exactly the failure mode, where a
name-only excerpt was cited for a mechanism. All 30 rows are `blocked-pending-re-source` with
`substanceAssessed: false`. Nothing has been re-sourced.

The 2 claims with no co-citation at all, both ligandrol, carrying 5 of the 29 excerpts:
`ligandrol-efficacy-lbm-healthy-men-001` (3) and `ligandrol-adverse-effect-hormone-suppression-001` (2).
Both trace to `basaria-2013-jgerontol-rct`, whose underlying work is the LGD-4033 trial (DOI
`10.1093/gerona/gls078`, PMCID `PMC4111291`) — a different rightsholder from DrugBank. A candidate route
exists via the `pmc` lane, but `pmc` is **Conditional**, not approved, so reuse scope does not suffice.
Recording a candidate is not proposing it, and no literature was deleted.
