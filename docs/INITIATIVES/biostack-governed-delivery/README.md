# BioStack Governed Delivery

This directory is the repository entry point for BioStack's governed-delivery initiative. Begin with the [Goal Charter](CHARTER.md), then confirm the [closed plan review](PLAN-REVIEW.md) before using the [authoritative spec registry](../../specs/INDEX.md).

## Governing records

- [Goal Charter](CHARTER.md) — ratified product doctrine, locked delivery decisions, authorization limits, dependency order, and initiative stop conditions.
- [Plan review](PLAN-REVIEW.md) — independent adversarial review and closure of the charter candidate.
- [P1 parcel spec](parcels/P1.md) — approved bootstrap contract for the governance documentation structure.
- [P1 Gate 2 dispatch record](dispatch/P1-GATE2.md) — repository-bound builder, branch, worktree, permissions, verification contract, evidence destination, and reviewers.
- [Spec lifecycle](../../specs/README.md) — repository rules for shaping, approving, dispatching, and closing parcel specs.
- [Out-of-band change record](OOB-2026-10-10-ops-maintenance.md) — owner-authorized maintenance and compliance-boundary repair made outside parcel dispatch (2026-10-10), with verification evidence and provenance.
- [Spec registry](../../specs/INDEX.md) — authoritative status and ownership index.

Only an approved active spec may be dispatched, and only in its coordinator-named branch and worktree. This initiative does not authorize production release or alter the independent production-readiness verdict.
