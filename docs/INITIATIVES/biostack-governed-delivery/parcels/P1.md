## Objective

Create the smallest repository-native governance bootstrap needed for later parcels: a discoverable Goal Charter lifecycle, a durable spec directory convention and index, minimal pointers to existing BioStack context, and clear repository-agent instructions. This parcel creates documentation structure only; it does not implement taxonomy semantics or enforcement.

## Required document contracts

### Spec registry

`docs/specs/INDEX.md` must use exactly these columns:

`Parcel | Status | Spec | Goal Charter | Delivery classes | Guidance classes | Branch/worktree | Owner | Review requirement | Closure`

For P1, the registry must link this spec and the governed-delivery charter, identify status `active`, record delivery classes `standard; architecture/risk-sensitive`, record guidance classes `not-applicable`, and state that branch/worktree, owner, reviews, and closure are recorded in the Gate 2 kickstarter and later closure manifest rather than invented in P1.

### Lifecycle

The lifecycle document must define:

1. Goal Charter ratification and plan-review closure precede parcel shaping.
2. A shaped spec is a review candidate until required independent reviews pass and coordinator triage closes.
3. Gate 2 names the approved spec hash, builder, branch, worktree, base commit, permissions, and checks.
4. Only approved active specs may be dispatched.
5. A spec moves to `done` only after merge and complete closure evidence; the index changes in the same governed change.
6. Failed or incomplete verification voids standing authorization.
7. Active specs contain no unresolved `TBD`, placeholder, ambient branch, or ambient worktree.
