# Integration Surfaces

| Surface | Producer | Consumer | Contract under test |
|---|---|---|---|
| Parsed protocol entries | Protocol parser | Research/application workflows | Aliases, segments, doses, and numeric parsing remain distinct and bounded |
| Interaction result | Graph/hints | User-facing stack analysis | Avoid/review states cannot be weakened by fallback ordering or invalid confidence |
| Research evidence | Staging translator | Evidence gate/user-facing output | Failure and synthetic provenance cannot become source-attributed evidence |
| Sidecar job state | Executor/worker | Polling client/store | Terminal state is monotonic and timed-out work cannot later overwrite it |
| Provider payload | API/application adapters | External endpoints | Sensitive source content is not transmitted without an explicit guarded boundary |
