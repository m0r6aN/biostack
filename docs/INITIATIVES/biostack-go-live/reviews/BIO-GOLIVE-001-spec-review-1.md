## Verified facts

- `CompoundCategory` is `Unknown = 0` through `Other = 10`. It has no Amino Acid or Research Compound member (`CompoundCategory.cs` lines 3–15).
- `SubstanceCanonicalizer.MapClassification` maps `Peptide`, `Pharmaceutical`, `Supplement`, `Hormone`, `SARM`, and `SERM` only. `Amino Acid`, `Research Compound`, `Small Molecule`, and every other string fall through to `Unknown` (`SubstanceCanonicalizer.cs` lines 97–111). Schema enums use the exact strings `Amino Acid` and `Research Compound`.
- `KnowledgeEntries.Classification` is `INTEGER` / `int` in migration `20260422125251_RecoverBillingTierEnforcement` (`.cs` line 76, designer lines 427–428). No later migration in `Migrations/` mentions `KnowledgeEntries`. The EF model does not convert that property to string. `BioStack.Api` does not call the canonicalizer. Worker Refresh runs only when the run mode is Refresh. A mapper deploy does not rewrite stored `0` rows.
- Committed Retatrutide at this HEAD is `Peptide`, with alias `triple agonist`. At pin `6c9d8ecc` the committed row is `Research Compound` without that alias. Other committed rows still use `Research Compound` (Melanotan II, Stenabolic). Glycine at this HEAD is `Amino Acid`.
- Promotion decision `go-live-library-2026-10-14-retatrutide` is `approve-for-promotion` and does not name a class.
- The spec text still says the public acceptance class is `ResearchCompound` and says not to treat the Peptide value as the reviewed class. Because Fact 5 calls that value uncommitted, the block does not hold on this tree. See F1.
- `DatabaseKnowledgeSource.GetAllCompoundsAsync` is `ToListAsync()` on the full entity. `KnowledgeService.GetAllCompoundsAsync` groups by canonical name and `MapToResponse` clears dose and schedule fields in memory. `KnowledgeEntryResponse` still has `JsonIgnore` on dose, schedule, pairing, reconstitution, and optimization fields (lines 18–50). `Program.cs` registers a parameterless `JsonStringEnumConverter`, so member names serialize as `AminoAcid`, `ResearchCompound`, `Sarm`, and `Serm`. The dossier card prints `entry.classification`.
- The spec forbids Refresh, production connection strings, live database writes, and go-live authorization. Its objective, promotion-authority, rollback, and forbidden sections match that boundary. No allowed file is a migration or a worker host.
- `SubstanceCanonicalizerClassificationTests` and `KnowledgeListProjectionTests` are named only in the spec. They are not on disk. That is expected for this review.
