# Accessibility Audit: /tools (deployed, biostack.cc)
**Standard:** WCAG 2.1 AA · **Date:** 2026-08-28 · **Method:** Claude in-app browser against production; viewport emulation 375x812 (mobile UA + touch), 768x1024, desktop; DOM audit script; console capture.

## Summary
Issues: 3 · Critical: 0 · Major: 1 · Minor: 2. Everything else on the ledger's lane-1 browser gate passed.

## Passed
- 375 / 768 / desktop: no horizontal scroll; syringe + vial visuals render prominently with worded labels ("Dry powder 5 mg / Liquid added 2 mL") and the "Educational representation only" boundary line.
- Zero console errors at all three widths.
- All images have alt; all SVGs labeled or aria-hidden; no unnamed buttons/links; single h1, logical H1>H2>H3 order; main + nav landmarks; lang=en; no positive tabindex; prefers-reduced-motion honored.
- Focus: browser default outline renders on focus (2.4.7 pass); marketing surfaces carry explicit focus-visible rings.
- Contrast: white-alpha text over #0B0F14 computes well above 4.5:1 (e.g. rgba(255,255,255,.62) ≈ 8.9:1).
